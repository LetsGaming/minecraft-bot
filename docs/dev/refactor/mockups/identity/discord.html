Discord messages

The same language as the dashboard, drawn in an approximation of Discord's dark message pane. Fonts, spacing and button widths differ from the real client.

Stripe and lamp

One colour per state, same four lamps as the dashboard
  • GreenOnline, done, back to normal. Title lamp 🟢.
  • AmberNot responding, degraded, blocked. Title lamp 🟡.
  • RedOffline and failures only. Title lamp 🔴. Leave, death and stop are never red.
  • GreyUnknown state, game events with no judgement. Title lamp ⚪ for unknown only.
  • SlateNeutral answers and work in progress: lists, stats, confirmations, progress. No lamp.
