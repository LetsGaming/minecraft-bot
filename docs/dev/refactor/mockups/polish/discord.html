Discord messages

An approximation of Discord's dark message pane drawn in HTML, not a screenshot of the real client. Layout widths, fonts and button wrapping on a phone must be checked once in a test guild. All names, ids and numbers are samples.

German is shown for status, stop confirmation, error, denial, players, mods, alerts, daily and whitelist. Bridge events are the same in both.

The rules these messages follow

TopicRule
Coloursuccess and online   failure and offline only   warning, needs a decision, not responding   info and neutral answers   events with no judgement and unknown   one celebration accent
TitlesAction or object in sentence case ("Could not load stats"). "Success" and "Error" only as a fallback.
EmojiOne leading status circle for server state (green online, amber not responding, red offline, grey unknown). None elsewhere, no emoji-only buttons.
FooterPage format "Page n/m" or an id that is needed. No "Requested by". Timestamp only on live data.
ErrorsProblem plus recovery in one or two sentences. Ephemeral. Denials come before the defer.
MentionsPing only on first failure. Recoveries, repeats and bridge text never ping. allowedMentions is explicit on every send.
Limits6000 total, 4096 description, 1024 field, 256 title, 45 modal label. Static strings are checked by a locale test in both languages.
