Discord embed language

The panes below are an approximation of Discord's dark theme, not a capture. Widths, wrapping and the phone layout are unverified until a run in a test guild. The colours are the dashboard's status colours, one to one.

Colour is status, one to one with the dashboard

Token values from tokens.css, used as the embed side bar
Online, success, applied#4ADE80. Also the only celebration colour (daily reward, challenge)
Not responding, degraded, warning#FBBF24, chip "Degraded"
Offline, failure, denial#F87171, chip "Offline"
Unknown, plain events#9AA1AC, join, leave, death
Pending, waiting for you#B7A1FF, confirmations, applications
Info, running#7CB4FF, answers and progress

Rules

TopicRule
ColourStatus only, the same seven values as the dashboard chips. Green success and online, amber warning and not responding, red failure and denial, grey unknown and plain events, violet pending (confirmations, applications), blue info and running. No separate celebration colour.
TitleNames the object or the action, sentence case, 256 characters at most. "Server stopped", "Could not reach smp". "Success" and "Error" only as a last fallback. The server name goes in the title, not the footer.
EmojiOne leading emoji, only for server state: green, yellow, red, white circle. None in other titles, none instead of a button label.
FieldsIdentity first, then measures, then free text last. At most three inline per row. 25 fields, 1024 characters each, 6000 for the whole embed. Builders split long lists into pages.
FooterEmpty by default. "Page n/m" lives on the pager row as a disabled button. Server id only when the guild has more than one server and the title does not already say it. No "Requested by".
TimestampOnly on live data: status and alerts. Times inside text use Discord timestamps so every viewer sees their own zone.
ErrorsProblem, then recovery, one or two sentences. No config paths, ids or stack text for non-admins. Always ephemeral.
Ephemeral or publicEphemeral: errors, denials, confirmations, personal data, config. Public: status, stats, leaderboards, moderation outcomes. The admin check runs before the reply is deferred, so a denial is never public.
ConfirmOne button row, a danger action and Cancel, with a 60 second expiry noted in the footer.
PaginationPrevious, a disabled "Page n/m", Next. After 3 minutes the buttons switch off instead of disappearing.
MentionsA role is pinged on the first failure and when severity rises. Recoveries and repeats never ping. Every alert and bridge message sets allowedMentions explicitly.
LanguageGerman uses du. One word per concept: "Server" for Minecraft, "Discord-Server" for the guild, "Bot-Admin", "Kanal".
